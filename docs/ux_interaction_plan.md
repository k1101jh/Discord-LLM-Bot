# Discord LLM Bot UX 및 상호작용 설계 가이드

이 문서는 Discord-LLM-Bot의 사용자 경험(UX), 대화 상호작용 방식, 드롭다운 UI 기반 세션 및 모델 관리 구조를 정의합니다.

---

## 1. 대화 상호작용 4대 핵심 모드

### 1) 일반 채널: 멘션 모드 (`@Bot <메시지>`)
- **작동 방식**: 일반 채널에서는 `@DiscordBot`으로 봇을 직접 멘션할 때만 챗봇이 응답합니다.
- **UX 포인트**: 답장(Reply) 형식으로 응답하여 질문과 대답의 관계를 명확히 표현합니다.

### 2) 전용 채널 / 스레드: 자동 대답 모드 (Auto-Response)
- **작동 방식**: 전용 AI 채널이나 대화 스레드 내부에서는 멘션 없이 입력하는 메시지에도 챗봇이 자동으로 답변합니다.
- **UX 포인트**: 대화의 연속성이 확보되며 자연스러운 1:1 대화 인터페이스를 제공합니다.

### 3) 채널 설정 토글 명령어 (`/llm toggle_auto_respond`)
- **작동 방식**: 서버 관리자(또는 권한자)가 특정 채널을 멘션 없이 대답하는 '자동 대답 채널'로 전환하거나 해제할 수 있습니다.

---

## 2. 드롭다운(Select Menu) 기반 세션 및 모델 관리 UI

### 1) 세션 관리 UI (`/llm list_sessions`)
- **인덱스 번호 부여**: 최근 세션들에 1번, 2번, 3번 번호를 부여하여 직관적으로 확인합니다.
- **드롭다운 선택**:
  - **`🔄 전환할 세션 선택`**: 클릭 한 번으로 이전 세션으로 전환.
  - **`🗑️ 삭제할 세션 선택`**: 세션 ID 입력 없이 드롭다운에서 선택 즉시 해당 세션 제거.

### 2) 모델 선택 UI (`/llm list_models`)
- **드롭다운 선택**: Ollama API에서 동기화된 모델 목록을 드롭다운 메뉴로 띄워 클릭 한 번으로 채널 세션 모델을 변경합니다.

### 3) 프롬프트 자동 생성 및 외부 설정 관리
- **`/llm generate_prompt description:<설명>`**: 타임아웃 방지 및 간결한 150자 이내의 한국어 System Prompt 작성 유도로 빈 응답을 방지합니다.
- **설정 파일 외부화 ([config/prompts.yaml](file:///d:/Programming/Projects/Discord-LLM-Bot/config/prompts.yaml))**:
  - 코드 수정 없이 파이썬 외부 YAML 파일에서 디폴트 챗봇 이름, 기본 프롬프트(`default_instructions`), 타임아웃, 파라미터를 손쉽게 변경할 수 있습니다.

---

## 3. 보안 가이드라인
- **Credentials 하드코딩 금지**: MongoDB 비밀번호, API 키 등 인증 정보는 소스 코드 내에 하드코딩하지 않으며 `.env` 파일과 환경 변수를 통해서만 가져옵니다.
